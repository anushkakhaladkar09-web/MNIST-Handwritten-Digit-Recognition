MNIST Handwritten Digit Recognition

Project Description

This project is based on Handwritten Digit Recognition using Python and Convolutional Neural Networks (CNN). It uses the MNIST dataset to recognize handwritten digits from 0 to 9.

Objectives

• To understand Artificial Intelligence and Deep Learning.

• To train a CNN model using the MNIST dataset.

• To recognize handwritten digits.

• To understand image classification using Python.

Technologies Used

• Python

• TensorFlow

• Keras

• Google Colab

• MNIST Dataset

Project Files

• mnist_handwritten_digit_recognition.ipynb – Project source code 

• mnist_digit_recognition.keras – Trained CNN model.

• Anushka AI report.pdf – Complete project report with output screenshots.

Methodology

1. Load the MNIST dataset.
2. Preprocess the images.
3. Build a CNN model.
4. Train the model.
5. Test the model.
6. Save the trained model.

Conclusion

This project demonstrates how CNN can recognize handwritten digits using the MNIST dataset. It provides practical knowledge of Python, deep learning and image classification.
